Tempo › System monitor

A super light system monitor for your top bar

Tempo puts your processor, memory and temperature in the GNOME top bar as two small rings and a number, and keeps the details one click away. It was built on a laptop that runs hot, so it does nothing unless something on screen needs to change.

What you get

  • Processor and memory as rings. One ring fills as the processor gets busier, the other as memory is used. No numbers to read; a glance is enough.
  • Temperature next to them, turning amber above 75 °C and red above 85 °C. More about temperature.
  • The details in one menu: processor usage and clock speed, load average, memory and swap, graphics and disk temperature, every fan, network speed, and the four busiest apps.
  • Internet speed as two small lines of fixed width, if you switch it on. More about network speed.
  • On the desktop instead, if you like: a floating system panel with the same readings and a little fan. More about the panels.
  • Yours to tune: every part has its own switch, readings refresh every 1 to 10 seconds (3 by default), and there are four palettes.

What it costs your computer

Measured on a 2019 laptop (Ryzen 5 3500U, GNOME Shell 42) with the project's own benchmark, which anyone can run with make bench. Figures are percent of one processor core.

One timer every 3 seconds reads three small files in /proc and one sensor. A ring is repainted only when its percentage changes, a label only when its text changes. How Tempo stays light.

Turn it on

  1. Install Tempo with the buttons above (the install guide has every step).
  2. That is all. The two rings and the temperature appear at the right of the top bar. Click them for the menu.
  3. Adjust what is shown under Settings, at the bottom of that menu.

Questions

How do I show CPU and RAM usage in the GNOME top bar?

Install Tempo. Two rings appear at the right of the top bar: one fills with processor use, the other with memory use. Click them for the exact numbers.

Does it work on Ubuntu, Fedora, Debian and Arch?

Yes. Tempo is a GNOME Shell extension, so it runs on any distribution with the GNOME desktop, versions 42 to 50: Ubuntu 22.04 to 26.04, Fedora, Debian 12 and 13, Arch, openSUSE and others. It does not run on KDE Plasma, Xfce or Cinnamon.

Will a system monitor slow my computer down?

This one was measured so that it does not: the rings, temperature and network speed add no measurable processor load. One timer every 3 seconds reads three small files, and nothing is redrawn unless a value changed.

Can I see which app is using the processor?

Yes. The menu lists the four busiest apps. They are only measured while the menu is open.

Can it show numbers instead of rings?

The numbers are one click away in the menu, and the floating system panel shows the percentages all the time. The top bar itself stays calm on purpose.
