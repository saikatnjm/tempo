Install Tempo

Tempo is a GNOME Shell extension. It works on any Linux distribution that uses the GNOME desktop, version 42 or newer, and takes about two minutes to install. You don't need administrator rights.

Download

Pick the file that matches your GNOME version. Both buttons always download the newest release.

GNOME 45 and newer GNOME 42, 43 and 44

Not sure which one? Step 1 below shows how to check, and the table further down lists each distribution. Looking for an earlier version? Every version is listed below with its own download links.

Steps

The same on every distribution. Open a terminal (Ctrl+Alt+T on most systems) for the commands.

  1. Check your GNOME version

    gnome-shell --version

    45 or higher: use the GNOME 45 and newer file. 42, 43 or 44: use the GNOME 42, 43 and 44 file. Lower than 42, or "command not found": Tempo can't run on this desktop (see below).

  2. Download the matching file

    Use the buttons above. Your browser saves it in your Downloads folder.

  3. Install it

    gnome-extensions install --force ~/Downloads/tempo-gnome45-plus.shell-extension.zip

    For GNOME 42 to 44, the file is called tempo-gnome42-44.shell-extension.zip. If your browser saved it elsewhere, use that path.

  4. Log out and back in

    GNOME only notices a new extension after you log in again. On the older X11 session you can instead press Alt+F2, type r and press Enter.

  5. Switch it on

    gnome-extensions enable tempo@saikatnjm.github.io

    Or open the Extensions app (or Extension Manager) and turn on Tempo. The rings appear on the right of the top bar.

  6. Optional: music visuals

    To let Tempo move with your music, click it, open Settings and turn on React to music. This needs the small parec tool. Most GNOME desktops already have it; the table below shows the package name if yours doesn't.

Update

Updating is installing again over the old version. Your settings are kept.

  1. See which version you have

    Click Tempo in the top bar, open Settings and scroll to About. The newest version is the first row of the table below.

  2. Download the newest file

    Use the buttons at the top of this page: they always fetch the newest version.

  3. Install it over the old one

    gnome-extensions install --force ~/Downloads/tempo-gnome45-plus.shell-extension.zip

    For GNOME 42 to 44 the file is tempo-gnome42-44.shell-extension.zip. --force is what replaces the old version.

  4. Log out and back in

    GNOME keeps running the old version until you log in again. Settings, About then shows the new version.

Installed from source? git pull && make install in the folder you cloned, then log out and back in. If you use the optional fan control and the release notes mention it, update that too: Settings, Fan control, Remove and then Install.

Uninstall

Removing Tempo takes one command, and nothing is left behind.

  1. If you installed the optional fan control, remove that first

    In Tempo's Settings, under Fan control, press Remove. (Or, from the source folder: sudo bash fan/install.sh remove.) Every fan goes back to the computer's own control. Skip this step if you never installed it.

  2. Uninstall Tempo

    gnome-extensions uninstall tempo@saikatnjm.github.io

    Or open the Extensions app (or Extension Manager), find Tempo and choose Remove. It disappears from the top bar at once; you don't need to log out.

  3. Optional: forget its settings too

    dconf reset -f /org/gnome/shell/extensions/tempo/

That is everything. Tempo is one folder in your home directory (~/.local/share/gnome-shell/extensions/tempo@saikatnjm.github.io); nothing else was ever installed. If you installed from source, make uninstall in the folder you cloned does step 2.

Only want it out of the way for a while? Switch it off instead: gnome-extensions disable tempo@saikatnjm.github.io, or the switch in the Extensions app. enable switches it back on, with your settings as they were.

Optional: fan control

If your computer starts its fans late, the optional tempo-fan service runs every fan Linux can control from its temperature, and adds a Fan mode switch to Tempo's menu (Cool, Full speed, Automatic). Tempo works without it; most computers don't need it.

To install it, open Tempo's Settings, scroll to Fan control and press Install. GNOME asks for your password once, because fans can only be driven with administrator rights. The same button removes it again.

No Install button in your Settings? A copy of Tempo installed through extensions.gnome.org comes without it, because that website does not let an extension run an installer. Two commands in a terminal do the same:

git clone https://github.com/saikatnjm/tempo.git
sudo bash tempo/fan/install.sh

To remove it again: sudo bash tempo/fan/install.sh remove. The button and the commands run the same installer: it lists the fans it will control before starting and installs nothing if there are none. ThinkPads need options thinkpad_acpi fan_control=1 in /etc/modprobe.d/thinkpad_acpi.conf first. It needs systemd, which every major distribution uses. Details and safety.

Not supported

Tempo only runs inside GNOME Shell, so it doesn't work on:

  • KDE Plasma (Kubuntu, KDE neon, Fedora KDE), Xfce (Xubuntu), Cinnamon (Linux Mint), MATE, LXQt, Budgie or COSMIC (Pop!_OS 24.04)
  • GNOME 41 and older, such as Ubuntu 20.04, Debian 11 and RHEL 9

If something doesn't work

"Extension tempo@saikatnjm.github.io doesn't exist"

GNOME hasn't loaded it yet. Log out and back in (step 4), then run the enable command again.

It doesn't appear in the top bar

Check its state:

gnome-extensions info tempo@saikatnjm.github.io

If the state is ERROR, you probably installed the file for the other GNOME version: install the other one (step 3) and log in again. If that doesn't help, these lines show why:

journalctl -b /usr/bin/gnome-shell | grep -i tempo
The music visuals don't move

Check that React to music is on, that sound is actually playing, and that parec is installed (table above). The player must support standard media controls: if it appears in GNOME's media controls in the notification list, it does.

The temperature isn't shown

Your computer has no temperature sensor Tempo recognises yet. Please open an issue with the output of grep . /sys/class/hwmon/hwmon*/name.

A floating panel can't be dragged

A panel on the desktop sits behind everything else, so a click only reaches it where nothing is in front. If your desktop shows icons (Ubuntu's Desktop Icons does), or you use the older X11 session, the click never arrives. In Settings, set Place them to On top of windows, move and size the panel, then switch back to On the desktop.

A floating panel is gone after unplugging a screen

It comes back to the main screen by itself, and returns to its place when the screen is plugged in again. To put a panel back where it started: gsettings --schemadir ~/.local/share/gnome-shell/extensions/tempo@saikatnjm.github.io/schemas reset org.gnome.shell.extensions.tempo float-stats-rect (or float-viz-rect for the visualizer).

I updated but still see the old version

Log out and back in: GNOME loads an extension once per login. If Settings, About still shows the old number after that, the file for the other GNOME version was installed; install the right one (step 3).

Still stuck?

Open an issue on GitHub with your distribution, the output of gnome-shell --version, and what you see.
