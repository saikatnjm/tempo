Tempo › CPU temperature

Your CPU temperature, always in view

Tempo shows the processor's temperature in the GNOME top bar and tints it amber above 75 °C and red above 85 °C, so a hot machine catches your eye before it slows itself down.

Download for GNOME 45+ GNOME 42, 43 and 44 Install guide
  • Free and open source
  • GNOME 42 to 51 on Ubuntu, Fedora, Debian, Arch and more
  • 250 KB, nothing else installed

What you get

  • Works out of the box on AMD (k10temp), Intel (coretemp) and most ARM boards. There is nothing to set up: Tempo reads the sensors the Linux kernel already offers.
  • A warning you cannot miss: amber above 75 °C, red above 85 °C.
  • Graphics card and disk temperature (NVMe and SATA) in the menu, read only while the menu is open.
  • Every fan and its speed in the same menu. More about fans.
  • Celsius or Fahrenheit.
  • Never in the way: sensors are read on a worker thread, so a slow sensor cannot make your desktop stutter.

Turn it on

  1. Install Tempo with the buttons above (the install guide has every step).
  2. That is all. The temperature is on by default and appears next to the rings.
  3. For Fahrenheit, click Tempo, open Settings and change the temperature unit.

Questions

How do I see my CPU temperature on Ubuntu without the terminal?

Install Tempo. The processor temperature appears in the top bar at once, and stays there. The same works on Fedora, Debian, Arch and any other distribution with GNOME 42 to 51.

Do I need lm-sensors?

No. Tempo reads the temperature files the Linux kernel provides directly, so there is nothing else to install or configure.

What temperature is too hot?

That depends on the processor; most slow themselves down somewhere between 90 and 105 °C. Tempo turns amber at 75 °C and red at 85 °C as a heads-up, not as a verdict.

The temperature is not shown. Why?

Your computer has no temperature sensor Tempo recognises yet. Please open an issue on GitHub with the output of grep . /sys/class/hwmon/hwmon*/name and it can be added.

Can it show the graphics card temperature too?

Yes, in the menu, together with the disk temperature and the fans, where the kernel reports them (AMD and Intel graphics, and Nouveau).
